# Metro Smart-Card Assignment 1 — Separate Programs

This folder contains 12 independent C++17 source files, one per assignment task. Each file has its own `main()` and should be compiled separately.

Compile an individual task, for example:
```bash
g++ -std=c++17 -Wall -Wextra Task06/Task06.cpp -o task06
./task06
```

Run each program yourself, capture the actual output, and commit task folders progressively. Tasks 1–3 and 11 include executable demonstrations of their concepts; also submit the written analysis, pseudocode, test evidence, and complexity discussion required by the assignment. The student must verify outputs and add personal details to the repository README.
